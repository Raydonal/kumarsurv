# Beta distribution function, mean-precision parametrization

Beta distribution function, mean-precision parametrization

## Usage

``` r
pbetamp(y, mu, phi)
```

## Arguments

- y:

  Numeric vector in `(0, 1)`.

- mu:

  Numeric vector, the mean, in `(0, 1)`.

- phi:

  Numeric vector, the precision parameter, `> 0`.

## Value

Numeric vector, `F(y)`.
