# Package index

## Kumaraswamy distribution

Quantile-parametrized Kumaraswamy density, distribution and quantile
functions.

- [`dkuma()`](https://raydonal.github.io/kumarsurv/reference/dkuma.md) :
  Kumaraswamy density, quantile-parametrized
- [`pkuma()`](https://raydonal.github.io/kumarsurv/reference/pkuma.md) :
  Kumaraswamy distribution function, quantile-parametrized
- [`qkuma()`](https://raydonal.github.io/kumarsurv/reference/qkuma.md) :
  Kumaraswamy quantile function, quantile-parametrized

## Beta distribution

Mean-precision beta density, distribution and quantile functions (the
comparison marginal).

- [`dbetamp()`](https://raydonal.github.io/kumarsurv/reference/dbetamp.md)
  : Beta density, mean-precision parametrization
- [`pbetamp()`](https://raydonal.github.io/kumarsurv/reference/pbetamp.md)
  : Beta distribution function, mean-precision parametrization
- [`qbetamp()`](https://raydonal.github.io/kumarsurv/reference/qbetamp.md)
  : Beta quantile function, mean-precision parametrization

## Model fitting

Gaussian-copula marginal regression, likelihood, estimation and
diagnostics.

- [`nll_copula()`](https://raydonal.github.io/kumarsurv/reference/nll_copula.md)
  : Negative log-likelihood of the Gaussian-copula marginal regression
- [`fit_copula()`](https://raydonal.github.io/kumarsurv/reference/fit_copula.md)
  : Fit the Gaussian-copula marginal regression by maximum likelihood
- [`fit_copula_multi_tau()`](https://raydonal.github.io/kumarsurv/reference/fit_copula_multi_tau.md)
  : Fit the model at several quantile levels, with a
  monotonicity/invariance check

## Residuals and simulation

- [`qresiduals()`](https://raydonal.github.io/kumarsurv/reference/qresiduals.md)
  : Predictive quantile residuals
- [`sim_copula()`](https://raydonal.github.io/kumarsurv/reference/sim_copula.md)
  : Simulate from the Gaussian-copula marginal regression

## Data

- [`platina`](https://raydonal.github.io/kumarsurv/reference/platina.md)
  : Weekly acute diarrheal disease incidence in Platina, SP (annual
  harmonic)
- [`platina_sem`](https://raydonal.github.io/kumarsurv/reference/platina_sem.md)
  : Weekly acute diarrheal disease incidence in Platina, SP (semiannual
  harmonic)
