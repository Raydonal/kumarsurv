# kumarsurv

Companion R package to:

> Ospina, R., Pimentel, J. S. and Cribari-Neto, F. *Copula-Based
> Kumaraswamy Regression for Anomaly Detection in Doubly Bounded Time
> Series* (manuscript submitted for publication).

A marginal regression model for time series in the unit interval, with a
Kumaraswamy marginal distribution parametrized directly by a quantile of
prescribed level and serial dependence induced by a Gaussian copula with
ARMA structure. Anomaly detection combines bootstrap-calibrated
goodness-of-fit tests, one-step prediction bands and a cumulative sum
(CUSUM) chart calibrated through the in-control average run length.
Applied to weekly acute diarrheal disease incidence in Platina, SP
(Brazil).

Site: <https://raydonal.github.io/kumarsurv/>

## Installation

``` r
# install.packages("remotes")
remotes::install_github("Raydonal/kumarsurv")
```

## Usage

``` r
library(kumarsurv)
data(platina)

X <- cbind(intercept = 1, trend = platina$trend, sin = platina$sin, cos = platina$cos)
Z <- cbind(intercept = 1, trend = platina$trend, sin = platina$sin, cos = platina$cos)
y <- platina$incidence
y[y == 0] <- 1e-7  # boundary replacement, see the paper's Section 6.1

fit <- fit_copula(y, X, Z, p = 1, q = 1, family = "kuma", tau = 0.5)
r <- qresiduals(fit)$r  # predictive quantile residuals
```

For `tau` other than the median, use
[`fit_copula_multi_tau()`](https://raydonal.github.io/kumarsurv/reference/fit_copula_multi_tau.md)
instead of a bare
[`fit_copula()`](https://raydonal.github.io/kumarsurv/reference/fit_copula.md)
call: the likelihood surface can have more than one interior stationary
point at a given `tau`, and
[`fit_copula_multi_tau()`](https://raydonal.github.io/kumarsurv/reference/fit_copula_multi_tau.md)
runs the monotonicity/invariance diagnostic the paper’s Section 6.3 and
Table 3 rely on to pick the right one. See
[`vignette("reproducing-the-paper")`](https://raydonal.github.io/kumarsurv/articles/reproducing-the-paper.md).

## Reproducing the paper

Every table, figure and numerical value in the paper and its
supplementary material is generated by a script, all 53 of them
browsable directly at
**[`inst/scripts/`](https://github.com/Raydonal/kumarsurv/tree/master/inst/scripts)**
on GitHub (also available at
`system.file("scripts", package = "kumarsurv")` once the package is
installed). `inst/scripts/run_all.R` runs them in dependency order:

``` r
scripts_dir <- system.file("scripts", package = "kumarsurv")
# fast scripts + figures:
source(file.path(scripts_dir, "run_all.R"))
# + the M = 300 / B = 300 Monte Carlo / bootstrap runs (slow, ~2h45):
Sys.setenv(RUN_PESADOS = "1")
source(file.path(scripts_dir, "run_all.R"))
```

`inst/scripts/copula_ml.R` is the archived, unexported copy of this
package’s own `R/copula_ml.R` (kept so the scripts’ own
`source("copula_ml.R")` calls still work standalone, outside the
package); `config_paths.R` resolves the scripts’ three legacy path
conventions regardless of the working directory.

Two known, environment-dependent non-reproducibilities, documented in
the paper’s supplementary material (Section S3): the Kumaraswamy
bootstrap $p$-value (`13_bootstrap_gof.R`; five runs and their Monte
Carlo standard error are reported), and fits where the likelihood is
nearly flat (`tau = 0.90`, near the ARMA stationarity boundary), where
the last digit of floating-point precision can select a different
stationary point.
